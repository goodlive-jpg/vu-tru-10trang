# Vũ Trụ - 10 Trang Animation

## Nội dung
Slide 10 trang về vũ trụ với animation hoạt ảnh:
- Trang 1: Big Bang - Vụ nổ với hạt bay ra
- Trang 2: Vũ trụ sơ khai
- Trang 3: Các thiên hà đầu tiên (xoắn ốc)
- Trang 4: Ngân Hà Milky Way
- Trang 5: Hệ Mặt Trời - **Tương tác**: Nhấn vào Mặt Trời và các hành tinh để xem giải thích
- Trang 6-10: Các chủ đề khác

## Chạy trên HTML
Mở file `index.html` bằng trình duyệt web.
- Điều hướng: Nút ← → hoặc phím mũi tên
- Tương tác: Click vào Mặt Trời, Sao Thủy, Sao Kim, Trái Đất, Sao Hỏa, Sao Mộc trên trang 5

## Chạy trên Python
```bash
python3 universe.py
```
Mô phỏng Big Bang và thông tin Hệ Mặt Trời.

## Chạy trên C++
```bash
g++ -std=c++17 universe.cpp -o universe && ./universe
```
Mô phỏng timeline Big Bang, bảng Hệ Mặt Trời và animation quỹ đạo.

## Tính năng
- Animation ngôi sao nhấp nháy
- Big Bang explosion animation
- Thiên hà xoắn ốc
- Quỹ đạo hành tinh
- Modal popup giải thích khi click hành tinh
